隐私说明

本扩展不会收集或上传你的任何个人信息。

  • API Key：存储在浏览器本地（chrome.storage.local），仅用于调用 DeepSeek API，不会发送到其他任何服务器。
  • 改写文本：你在扩展中输入或选中的文本会直接发送到 api.deepseek.com 以生成改写结果。文本不会被本扩展开发者收集或存储。
  • 改写历史：仅存储在你本地浏览器中，随时可以清除。
  • 第三方服务：DeepSeek 的隐私政策请参见 platform.deepseek.com/privacy。
